# Slide deck — source files

This folder holds the source of the project's slide deck: `deck.json` (deck
metadata, slide order, outline, fonts) and `slides/*.html` (one file per
slide, in a restricted HTML/CSS subset for a fixed 1920×1080 canvas).

**Live, viewable/presentable version:** https://claude.ai/artifact/Dpbjwb6FEhRvmuvMpfW19X
(private Claude Artifact — share it from its own Share menu to let others open it).

These files are the deck's content, not a standalone webpage — they're not
meant to be opened directly in a browser. They're committed here so the
deck's content lives in the repo alongside the code and results, matching
everything else in `report/`.
